# Changelog

## 0.1.0

- Initial release
- Expanded inventory from 3 to up to 10 slots via Transpiler patch
- Configurable key bindings for extra slots (slots 4–10)
- UI slot and frame cloning for visual consistency
- Extended slot save/load persistence
- Hide vanilla inventory frame option
- Compatible with Artisan's save format (shared PLAYER.{id}.INV prefix)
